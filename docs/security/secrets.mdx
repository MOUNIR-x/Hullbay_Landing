# Chiffrement et gestion des clés

La sécurité des données au repos est assurée par un chiffrement robuste (AES-256-GCM) pour toutes les données persistées dans la base de données de contrôle, et par les mécanismes natifs de Docker Swarm pour les données en cours d'exécution.

---

## 1. Chiffrement au repos (AES-256-GCM)

Toutes les données critiques nécessaires au fonctionnement autonome de Hullbay sont chiffrées avant d'être écrites dans la base PostgreSQL :

- **Clés SSH privées (Servers)** : Utilisées pour les tunnels SSH d'administration.
- **Tokens de Registres Docker (Registries)** : Utilisés pour tirer des images privées.
- **Seeds TOTP (Users)** : Utilisés pour valider l'authentification à deux facteurs.

### La Clé Maîtresse (Master Key)

L'algorithme de chiffrement utilise une clé maîtresse unique, définie par la variable d'environnement `MFA_ENCRYPTION_KEY` générée lors de l'installation (dans le fichier `.env`). 
Le chiffrement est couplé au mode GCM (Galois/Counter Mode) qui assure également l'intégrité de la donnée.

:::danger Perte de la clé maîtresse
Si vous perdez le fichier `.env` contenant la `MFA_ENCRYPTION_KEY`, **toutes les données chiffrées deviennent définitivement irrécupérables**. Vous devrez recréer manuellement les tokens de registres, reconnecter les serveurs et réinitialiser les MFA de tous les utilisateurs.
:::

---

## 2. Le modèle Write-Only des Docker Secrets

Les secrets applicatifs (ceux que vous créez pour vos projets) ne sont pas stockés dans la base de données de Hullbay. Ils exploitent directement la fonctionnalité **Docker Secrets** du cluster Swarm.

- **Chiffrement Raft** : Swarm chiffre ces secrets dans son Raft store et les distribue de manière sécurisée (TLS mutuel) uniquement aux nœuds workers qui en ont besoin.
- **Write-Only API** : L'API de Hullbay permet de créer (POST) ou de lister (GET) le nom des secrets, mais ne propose **aucune route** permettant de lire la valeur brute d'un secret. Une fois injecté, le secret quitte le périmètre lisible de l'administration.
